# Glow 대시보드

사주 · 신체 · 정신 · 커리어 · 투자를 한곳에서 보는 개인 대시보드.
개인 구글시트에 붙은 Apps Script 웹 앱으로 동작하고, 모든 기록은 그 시트에 저장된다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체. 웹 앱에서는 시트에 저장하고, 브라우저로 그냥 열면 예시 데이터로 미리보기 (브라우저 저장소) |
| `Code.gs` | 웹 앱 진입점(`doGet`), 시트 읽기(`getData`)·쓰기(`saveAll`), 최초 설정(`setup`) |
| `Saju.gs` | 사주 원문. `setup()`이 `saju` 탭에 넣는다 |
| `appsscript.json` | 매니페스트 (clasp로 올릴 때 사용) |

## 처음 설정 (손으로 할 때, 10분)

1. Google Drive에서 **새 스프레드시트**를 만든다. (이름 예: `Glow 대시보드`)
2. 메뉴 **확장 프로그램 → Apps Script**를 연다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 붙여넣는다.
4. 왼쪽 **파일 ＋ → 스크립트**, 이름 `Saju` → `Saju.gs` 내용 붙여넣기.
5. **파일 ＋ → HTML**, 이름 `index` → `index.html` 내용 붙여넣기.
6. 저장(Ctrl+S) 후 위쪽 함수 목록에서 **`setup`** 선택 → **실행**.
   - 권한 요청이 뜨면 본인 계정 선택 → "확인되지 않은 앱" 화면에서 **고급 → (프로젝트 이름)으로 이동** → 허용.
   - 시트에 `inbody · workouts · checks · principles · settings · saju` 탭이 생긴다.
7. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **나만** (로그인 없이 열고 싶으면 "모든 사용자")
   - **배포** → 나오는 **웹 앱 URL**이 대시보드 주소.
8. 폰에서는 그 URL을 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있다.

## 코드를 고친 뒤

Apps Script 편집기에 바뀐 파일을 다시 붙여넣고 **배포 → 배포 관리 → (연필) → 버전: 새 버전 → 배포**.
URL은 그대로 유지된다.

## 시트 구조

| 탭 | 열 | 비고 |
|---|---|---|
| `inbody` | 측정일, 체중, 골격근량, 체지방률, 기초대사량 | 시트에 직접 입력해도 됨 |
| `workouts` | 날짜, 운동함 | 운동한 날. 체크박스, 직접 입력 시 `O`·`v`도 인식. 예전 부위별 열 형식은 한 부위라도 체크된 날을 운동한 날로 읽음 |
| `plans` | 날짜, 계획 부위 | 그날 할 부위. 예: `등, 이두` (가슴·어깨·등·하체·이두·삼두·전완근·복근·워킹·러닝) |
| `rm` | 날짜, 부위, 1RM(kg) | 부위별 1RM 이력. 최근 값이 버튼에 표시됨 |
| `cardio` | 날짜, 종목, 시간(분) | 워킹·러닝 시간 |
| `checks` | 날짜, 단단함, 자신감, 여유, 원칙 지킴, 메모 | 1~5점. 예전 `부드러운 태도`는 여유로 읽음 |
| `principles` | 순서, 원칙 | |
| `settings` | 항목, 값 | 목표 체중, 목표 체지방률, 누적 기준 월·횟수, 지향 묘사, 정체성 문장, 키워드(쉼표 구분) |
| `saju` | 원문 | A2 한 칸에 원문 전체 |

- `누적 기준 월`·`누적 기준 횟수`: 앱을 쓰기 전 운동 기록. 기본값 `2026-09`·`100`이면 2026년 누적 = 100 + 10월부터의 앱 기록.
- 달력은 일요일 시작이고, 공휴일은 구글 캘린더 "대한민국의 휴일"에서 읽는다 (처음 열 때 캘린더 권한을 한 번 묻는다). 권한이 없으면 화면에 내장된 2026~2027년 공휴일 표를 쓴다.
- 날짜는 `2026-10-06`, `2026.10.6`, `2026/10/06` 모두 읽는다.
- 화면에서 저장하면 해당 탭을 통째로 다시 쓴다. 대시보드를 열어 둔 채 시트를 직접 고쳤다면, 대시보드를 새로고침한 뒤 작업할 것 (안 그러면 화면의 옛 값으로 덮어쓴다).
