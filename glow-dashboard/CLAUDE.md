**신체** (가장 많이 다듬은 곳)
- 위에서부터: **목표 달성**(종합 원형 그래프 + 체중·체지방률·제지방량 원형 그래프, 목표 수정) → 오늘 카드("오늘은 등 · 이두 하는 날" + 완료 버튼) + 운동 기록 타일 → 달력 + 날짜 패널 → 인바디 입력 → 인바디 그래프.
- 부위(계획용): 대근육 가슴·어깨·등·하체 / 소근육 이두·삼두·전완근·복근 / 유산소 워킹·러닝. (유산소는 한때 삭제했다가 계획 항목으로 다시 추가함.) 그룹 제목은 "대근육"처럼 "계획" 없이.
- **어떤 부위를 운동했는지는 기록하지 않는다.** 날마다 "운동함" 여부만(칸 채움 + ★).
- 대신 **날짜별 계획 부위**를 달력에 글자로 표시. 계획했는데 못 한 지난 날은 주황 테두리.
- 주간 루틴 기능은 만들었다가 **삭제함**(요청). 부위별 월 횟수 화면도 삭제함.
- 달력은 네이버·구글 캘린더처럼 **일요일 시작**, 이웃 달 날짜 흐리게, 일·공휴일 빨강, 토 파랑, 공휴일 이름 표시. "이번 주"도 일~토.
- 운동 기록 타일의 **목표 달성 = 이 달 운동한 날 ÷ 12일(고정, `MONTH_TARGET`)**. 진행 막대 + "목표까지 n일". (예전의 "계획한 날 중 운동한 날" 방식은 요청으로 바꿈)
- 연간 누적: **2026년은 9월까지 100회**에서 시작(`누적 기준 월/횟수`). 그 이전 앱 기록은 중복으로 세지 않는다.
- 달성률 = (최근 − 첫 인바디) / (목표 − 첫 인바디), 0~100%로 자른다. 종합 = 세 항목 평균.

**시작 화면(로그인)**
- 앱을 열면 시작 화면에서 구글 계정을 확인하고 "시작하기"를 눌러야 들어간다. 허용 계정은 `Code.gs`의 `OWNER_EMAIL`(forsythia1226@gmail.com) 하나.
- 서버 함수(`getData`·`saveAll`·`getHolidays`)는 `assertOwner_()`로 계정을 한 번 더 확인한다. 화면은 `whoAmI()` 확인 뒤에만 서버를 부른다(`SIGNED_IN`).
- 앱 자체 비밀번호는 만들지 않는다(구글 로그인이 인증). 미리보기 모드에서는 "미리보기 시작" 버튼만.

**기록 (1RM · 유산소 시간)**
- 날짜 패널의 부위 카드 = **이름(누르면 그날 계획 토글) + 바로 아래 드롭다운**. 근력은 1RM(kg: 1~50 0.5단위, 50~300 2.5단위, 빈 칸 글자 = 최근 1RM), 워킹·러닝은 시간(분: 5~180, 5단위). 값은 이름 아래 가운데 **작은 캡션**(`.val`, 배경 없음·hover 때만 옅은 배경, 숫자 .82rem 본문 글꼴 — 크고 굵은 알약은 어색하다는 피드백으로 바꿈)에 "62.5 kg ▾" / "최근 60kg"(흐림) / "+ kg"로 보이고, 투명한 select가 알약 전체를 덮어 어디를 눌러도 목록이 열린다. 선택한 날짜로 저장, 비우면 그날 기록 삭제. 시트: `rm`(날짜·부위·1RM(kg)), `cardio`(날짜·종목·시간(분)).
- 패널의 "운동 완료 체크" 버튼은 삭제함. 대신 **기록을 입력한 날은 자동으로 운동함(★)**(미래 날짜 제외, 지워도 자동 취소는 안 함). 오늘은 오늘 카드의 완료 버튼도 있음.
- 근육 아이콘은 넣었다가 요청으로 삭제함.

## 함정 (실제로 겪은 것)

- **선언 순서(TDZ):** 저장소를 읽는 코드(`let S = ...`, `normBody`, `normChecks`)가 쓰는 상수는 그보다 **위에** 선언해야 한다. 아래에 두면 화면이 통째로 안 뜬다.
- **Apps Script 문법:** `Code.gs`는 `var`·`function`만 쓴다(`??`, `?.` 쓰지 않음). 날짜 판별은 `instanceof Date` 대신 `isDate_()`.
- **시트 이전:** 열 구성을 바꿀 땐 `setup()`이 기존 머리글을 덮어쓰지 않게 하고, 읽기는 머리글 이름 기준으로 한다(예전 `코어`→복근, `부드러운 태도`→여유, 부위별 운동 열→운동함).
- **생성 스크립트로 코드를 넣을 때** 정규식 백슬래시(`\s`)가 빠진 적이 있다. 넣은 뒤 `grep`으로 확인.
- **claude.ai 아티팩트**에서는 외부 통신이 막혀 시트 저장이 안 된다(그래서 Apps Script로 옮김). `alert/confirm/print`도 안 된다 → 두 번 누르기 확인 방식 사용.
- **`hidden` 속성:** claude.ai 미리보기는 `[hidden]{display:none!important}`를 깔아 주지만 Apps Script 웹 앱은 아니다. index.html 스타일 맨 끝의 같은 규칙을 지우지 말 것(지우면 시작 화면이 안 닫히고 사주 하위 탭이 겹친다). jsdom은 `!important`를 무시하고 뒤 규칙을 우선하므로 이 규칙은 맨 끝에 둬야 테스트도 맞다.
- 시트를 열어 둔 채 직접 고쳤다면 대시보드를 새로고침한 뒤 입력해야 덮어쓰지 않는다.
