# [대한전선] 일일현안 보고 — 자동화 AI 에이전트

각 부문·팀 담당자가 일일 현안을 입력하면 Google Sheets 에 즉시 저장되고,
경영기획팀이 버튼 한 번으로 Claude 를 통해 경영진용 통합 보고서를 생성하는
Streamlit 웹 애플리케이션입니다.

제출된 원본 데이터는 **작성일시 기준 48시간이 지나면 자동으로 삭제**됩니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `issue_app.py` | Streamlit UI (사이드바 조직 선택 / 현안 입력 / 경영기획팀 전용 화면) |
| `config.py` | 조직 구조(6개 대부문 + 팀), 시트·보관 정책·LLM·데모 설정 |
| `sheets_core.py` | Google Sheets 접근 코어 (Streamlit 비의존 — 앱과 스케줄러가 공용) |
| `issue_store.py` | 앱용 저장소 레이어 (백엔드 선택 + Streamlit 캐싱) |
| `report_generator.py` | Claude API 호출 및 통합 보고서 프롬프트 |
| `purge_job.py` | **정시 삭제 잡** — 스케줄러에 등록해 접속과 무관하게 실행 |
| `run_demo.bat` / `run_app.bat` | 더블클릭 실행 파일 (시연용 / 운영용) |
| `run_purge.bat` | Windows 작업 스케줄러용 실행 배치 |
| `.github/workflows/purge.yml` | GitHub Actions 매시 정각 삭제 워크플로 |
| `org_store.py` | 조직도(부문·팀) 저장·수정 — `organization.json` |
| `ui_theme.py` | 공용 UI 테마 (뉴스 리포트 앱과 동일한 톤앤매너 CSS) |
| `demo_store.py` | 시연용 로컬 JSON 백엔드 + 샘플 데이터 |

> 같은 리포지토리의 `app.py` / `news_service.py` / `sheet_store.py` 는 별개의
> 네이버 뉴스 리포트 앱입니다. 본 앱과 서로 영향을 주지 않습니다.

## 0. 담당자가 직접 해야 할 일 (체크리스트)

코드는 모두 준비되어 있습니다. 아래 항목만 사람이 처리하면 운영에 들어갈 수 있습니다.

| # | 할 일 | 담당/소요 | 없으면 생기는 일 |
|---|---|---|---|
| 1 | **Google Cloud 프로젝트 생성 + Sheets API 활성화** | IT/본인, 5분 | 시트 저장 불가 |
| 2 | **서비스 계정 생성 → JSON 키 발급 → `service_account.json` 으로 저장** | 5분 | 인증 실패 |
| 3 | **스프레드시트 생성 후 서비스 계정 `client_email` 을 편집자로 공유** | 2분 | `PermissionError` (가장 흔한 실수) |
| 4 | **`.env` 작성** (`ISSUE_SHEET_ID`, `ANTHROPIC_API_KEY`) | 3분 | 앱이 데모 안내만 표시 |
| 5 | **Anthropic API 키 발급 및 결제 수단 등록** (console.anthropic.com) | 10분 | 보고서 생성 버튼만 오류 |
| 6 | **정시 삭제 스케줄러 등록** (7장 A/B/C 중 택 1) | 10분 | 접속 없을 때 데이터가 48시간 넘게 남음 |
| 7 | **`config.py` 의 실제 조직도 반영** (현재 팀명은 예시값) | 10분 | 실제 팀명과 불일치 |
| 8 | **사내 보안·정보보호 검토** (외부 LLM 전송 범위, 시트 접근 권한) | 조직에 따라 다름 | 배포 승인 지연 |
| 9 | **배포 위치 결정** (사내 서버 / Streamlit Cloud / 사내 PC) 및 접근 제어 | 협의 필요 | 아래 주의 참고 |

**꼭 결정이 필요한 사항 두 가지**

1. **접근 제어** — 현재 앱에는 로그인이 없습니다. 링크를 아는 사람은 누구나 조회·입력이
   가능하므로, 사내망 전용 배포 또는 Streamlit 인증(`st.login` / 리버스 프록시 SSO)을
   붙일지 결정해야 합니다. "경영기획팀 전용" 화면도 현재는 사이드바에서 해당 팀을
   고르면 열리는 UI 구분일 뿐, 권한 통제가 아닙니다.
2. **48시간 후 원본이 사라진다는 점** — 통합 보고서는 별도 저장되지 않습니다.
   보고서 아카이브가 필요하면 생성 결과를 별도 시트/드라이브에 저장하는 기능을
   추가해야 합니다(현재 미구현).

> 시연만 먼저 해 보려면 1~5번을 건너뛰고 8장 **데모 모드**로 바로 실행하면 됩니다.

## 1. 설치

```bash
pip install -r requirements.txt
```

## 2. Google Sheets 준비

1. Google Cloud Console 에서 프로젝트를 만들고 **Google Sheets API** 를 활성화합니다.
2. **서비스 계정**을 생성하고 JSON 키를 내려받아 프로젝트 루트에
   `service_account.json` 으로 저장합니다. (`.gitignore` 에 등록되어 있습니다.)
3. 데이터를 저장할 스프레드시트를 만들고, 서비스 계정의 `client_email` 을
   **편집자**로 공유합니다.
4. 스프레드시트 URL(`https://docs.google.com/spreadsheets/d/<ID>/edit`)의 `<ID>` 를
   `.env` 의 `ISSUE_SHEET_ID` 에 넣습니다.

워크시트(기본 이름 `issues`)와 헤더는 앱이 최초 실행 시 자동으로 만듭니다.

| 작성일시 | 날짜 | 대부문 | 팀명 | 작성자 | 일일현안내용 |
|---|---|---|---|---|---|
| 2026-09-08 09:12:03 | 2026-09-08 | 에너지부문 | 에너지영업팀 | 홍길동 | ... |

## 3. 환경 변수

`.env.example` 을 `.env` 로 복사한 뒤 값을 채웁니다.

```bash
cp .env.example .env
```

```dotenv
GOOGLE_SERVICE_ACCOUNT_FILE=service_account.json
ISSUE_SHEET_ID=<스프레드시트 ID>
RETENTION_HOURS=48
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-opus-5
```

`.env` 와 `service_account.json` 은 `.gitignore` 에 등록되어 있어 커밋되지 않습니다.
Streamlit Cloud 등에 배포할 때는 키 파일 대신 `st.secrets` 의
`[gcp_service_account]` 섹션과 `ISSUE_SHEET_ID` 를 사용해도 동작합니다.

## 4. 실행

### 가장 쉬운 방법 — 실행 파일 더블클릭

| 파일 | 용도 |
|---|---|
| `run_demo.bat` | **시연용** — Google Sheets/API 키 없이 로컬 파일로 동작 |
| `run_app.bat` | **운영용** — Google Sheets + Claude API 사용 |

더블클릭하면 파이썬 확인 → 누락 패키지 자동 설치 → 앱 실행 → 브라우저 자동 열기까지
진행됩니다. 검은 창은 서버이므로 **닫지 말고 켜 두세요**(닫으면 앱이 종료됩니다).
문제가 생기면 창에 오류가 남고 `아무 키나 누르십시오`에서 멈추므로 메시지를 확인할 수 있습니다.

환경만 점검하려면: `run_demo.bat check`

### 터미널에서 직접 실행

```powershell

```

> `streamlit` 명령이 PATH에 없을 수 있으므로 `python -m streamlit` 형태를 권합니다.

Google Sheets/Claude 설정 없이 먼저 시연하려면 8장 **데모 모드**를 참고하세요.

3. **[현안 제출]** 클릭 시 제출 시각(Timestamp)과 함께 시트에 새 행으로 저장됩니다.

### 경영기획팀 (경영부문 › 경영기획팀 선택 시 노출)
- **[오늘의 통합 보고서 생성]** — 시트에서 오늘 날짜 데이터를 읽어 Claude 에 전달하고,

- **[48시간 경과 데이터 수동 정리]** — 보관 기한이 지난 행을 즉시 삭제합니다.

## 6. 48시간 보관 정책 동작 방식

- **자동**: 앱이 로드될 때마다 `issue_store.run_auto_purge()` 가 호출됩니다.
  실제 시트 스캔·삭제는 10분 단위 캐시 버킷으로 제한되어(`auto_purge`),
  rerun 마다 Google API 쿼터를 소모하지 않습니다.
- **수동**: 경영기획팀 화면의 정리 버튼으로 즉시 실행할 수 있습니다.
- 삭제 대상은 `작성일시`가 `현재 시각 - RETENTION_HOURS` 이전인 행입니다.
  삭제는 아래쪽 행부터 연속 구간 단위로 수행되어 행 번호가 밀리지 않습니다.
- 작성일시를 해석할 수 없는 행은 **삭제하지 않습니다**(데이터 보호).
- 보관 기간은 `.env` 의 `RETENTION_HOURS` 로 조정할 수 있습니다.

> 통합 보고서는 원본 데이터가 삭제되기 전에 생성·다운로드해 두어야 합니다.
> 시트에는 원본만 보관되며, 생성된 보고서는 별도로 저장되지 않습니다.

## 7. 접속과 무관한 정시 삭제 (스케줄러 등록)

앱 안의 자동 정리는 "누군가 앱을 열었을 때"만 동작합니다. 접속과 무관하게 정해진
시각에 삭제하려면 `purge_job.py` 를 스케줄러에 등록하세요. 이 스크립트는 Streamlit 에
의존하지 않으므로 서버·PC·CI 어디서든 단독 실행됩니다.

```bash
python purge_job.py            # 삭제 실행
python purge_job.py --dry-run  # 대상 건수만 확인 (삭제 안 함)
python purge_job.py --hours 24 # 보관 시간 일시 변경
```

종료 코드 0 = 성공, 1 = 실패이므로 스케줄러가 실패를 감지할 수 있습니다.

### 방법 A. GitHub Actions (PC를 켜 둘 필요 없음 — 권장)

`.github/workflows/purge.yml` 이 이미 포함되어 있으며 **매시 정각**에 실행됩니다.
저장소 `Settings > Secrets and variables > Actions` 에 두 개만 등록하면 끝입니다.

| Secret 이름 | 값 |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | `service_account.json` 파일 **내용 전체**를 붙여넣기 |
| `ISSUE_SHEET_ID` | 스프레드시트 ID |

`Actions` 탭의 **Run workflow** 버튼으로 즉시 테스트할 수 있습니다.

### 방법 B. Windows 작업 스케줄러 (사내 PC/서버 상시 가동 시)

관리자 PowerShell 에서 한 번만 등록합니다.

```powershell
schtasks /create /tn "IssueReportPurge" /tr "C:\Users\<사용자>\Desktop\claude code\run_purge.bat" /sc hourly /st 00:00
schtasks /run  /tn "IssueReportPurge"    # 즉시 실행 테스트
schtasks /query /tn "IssueReportPurge"   # 등록 확인
```

실행 로그는 `purge.log` 에 쌓입니다.

### 방법 C. Linux 서버 cron

```cron
0 * * * * cd /srv/issue-report && /usr/bin/python3 purge_job.py --log-file purge.log
```

> 세 방법 모두 앱 내부 자동 정리와 함께 써도 안전합니다. 삭제는 멱등적이라
> 중복 실행돼도 이미 지워진 행을 다시 지우지 않습니다.

## 8. 배포 전 시연 (데모 모드)

Google Sheets 계정도 Claude API 키도 없이, 실제와 **동일한 화면과 삭제 규칙**으로
전체 흐름을 시연할 수 있습니다.

```bash
# Windows PowerShell
$env:DEMO_MODE="true"; streamlit run issue_app.py

# macOS / Linux
DEMO_MODE=true streamlit run issue_app.py
```

데모 모드에서는 데이터가 Google Sheets 대신 `demo_data.json` 로컬 파일에 저장되고,
`ANTHROPIC_API_KEY` 가 없으면 보고서가 규칙 기반 자리표시자로 생성됩니다.
(키가 있으면 데모 모드에서도 실제 Claude 가 보고서를 씁니다.)

### 시연 시나리오 (약 3분)

1. **샘플 데이터 주입** — 좌측 남색 패널 하단 `🧪 시연 도구 > [샘플 데이터 채우기]`
   오늘 현안 9건과 **이미 48시간이 지난 만료 데이터 3건**이 함께 들어갑니다.
2. **담당자 입력 시연** — 좌측 패널에서 `에너지부문` 선택 후 팀 이름 클릭 →
   작성자·현안 입력 → `[현안 제출]`.
   저장 즉시 하단 "오늘 제출 내역"에 작성일시와 함께 나타납니다.
3. **조직 편집** — 팀 목록 오른쪽 🗑️ 로 팀을 빼고, 하단 입력창 + [➕ 추가] 로 팀을 넣습니다.
4. **경영기획팀 화면 진입** — `경영부문` › `경영기획팀` 선택 시 우측 열이 전용 화면으로 바뀝니다.
   - `📋 통합 보고서`: 생성 버튼 → 핵심 요약 + 부문/팀별 개조식 보고서 프리뷰 →
     `.md` / `.txt` 다운로드.
   - `🗑️ 데이터 보관 현황`: 전체 행 수, **삭제 대상(만료)** 건수, 행별 보관 상태
     (예: `41시간 12분 남음`, `만료 (삭제 대상)`) 표.
5. **보관 정책 시연** — `[48시간 경과 데이터 수동 정리]` 클릭 →
   만료 3건만 사라지고 오늘 데이터는 그대로 남는 것을 표에서 확인합니다.
6. **정시 삭제 시연** — 터미널에서 `python purge_job.py --dry-run` 을 실행해
   앱과 무관하게 동작하는 잡을 보여줍니다. (데모 모드가 아닌 실제 시트 대상)
7. **초기화** — `[데모 데이터 전체 삭제]` 로 언제든 처음 상태로 되돌립니다.
   (조직도는 `[⚙️ 대부문 관리 > ↩️ 기본 조직도로 초기화]`)

아이콘 섹션 헤더, 알약형 날짜 배지.

## 9. 조직 변경 (부문·팀 추가/삭제)

### 화면에서 직접 수정 — 코드 수정 불필요

좌측 남색 패널에서 바로 편집합니다.

- **팀 추가** — 패널 하단 `새 팀 입력` + **[➕ 추가]** (선택된 대부문 아래로 들어감)
- **팀 삭제** — 팀 목록 각 줄 오른쪽 **🗑️** 아이콘
- **팀 선택** — 팀 이름을 클릭하면 파란색으로 활성화되고 가운데 입력 폼이 바뀝니다
- **대부문 추가 / 삭제 / 초기화** — 패널의 **[⚙️ 대부문 관리]** 펼치기

변경 결과는 `organization.json` 파일에 저장되어 앱을 재시작해도 유지됩니다.

**동작 규칙**
- 팀을 삭제해도 **이미 제출된 과거 데이터는 지워지지 않습니다**(시트에 그대로 남습니다).
  보고서에도 계속 반영되며, 48시간 보관 정책에 따라서만 사라집니다.
- 중복 이름은 추가되지 않습니다.
- 경영기획팀(`ADMIN_TEAM`)과 경영부문(`ADMIN_DIVISION`)은 삭제할 수 없습니다.
  삭제하면 통합 보고서 화면에 들어갈 수 없기 때문입니다. 바꾸려면 `config.py` 의
  `ADMIN_TEAM` / `ADMIN_DIVISION` 을 먼저 수정하세요.
- 팀이 하나도 없는 대부문은 입력 폼 대신 안내 문구가 표시됩니다.

> **배포 시 주의** — Streamlit Cloud 처럼 파일시스템이 재배포마다 초기화되는 환경에서는
> `organization.json` 이 사라집니다. 그런 환경에서는 조직 확정 후 이 파일을 저장소에
> 커밋하거나, `config.py` 의 기본값을 직접 수정하세요.

### 기본값(시드) 수정

`config.py` 의 `ORGANIZATION` 딕셔너리가 최초 기본값입니다.
`organization.json` 이 없을 때만 사용됩니다.

```python
ORGANIZATION = {
    "에너지부문": ["에너지영업팀", "에너지설계팀", "신규팀"],
    ...
}
```

## 10. 제목 변경

`config.py` 의 `APP_TITLE`(기본값 `[대한전선] 일일현안 보고`) 또는 `.env` 의
`APP_TITLE` 환경변수로 바꿀 수 있습니다. 브라우저 탭 제목과 화면 제목에 함께 적용됩니다.
